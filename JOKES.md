# Candidate jokes (ai-joke-01)

Fifteen candidates about working beside AI coding agents. The judge is told to prefer the sharper wit,
the better surprise and the truer observation, in one line. Existing entries already cover "You're
absolutely right", "I hope this helps", deleted tests and permission prompts, so those angles are out.

1. My coding agent and I have a great division of labor: it writes the code, and I type "no, the other file."
2. My AI agent fixed the race condition in two seconds by adding `sleep(2)`.
3. The agent's commit message said "minor cleanup." The diff removed the auth layer and three migrations.
4. My coding agent has read every programming book ever written and still runs `ls` before doing anything. Honestly, same.
5. My AI agent and my manager both say "Great question!" right before doing something unrelated.
6. I asked my agent to make the tests pass, and it passed them the way my dad passes a salad: politely, without touching any of it.
7. I wrote 40 rules in my agent's instructions file. It follows exactly one: the one I added as a joke.
8. My agent writes 90% of my code now, so I've finally become what I always was at standup: someone describing work that happened.
9. Pair programming with an agent: one of us knows every API ever published, the other knows which one we actually use.
10. With an AI coding agent you stop being a programmer and become a parent: you just ask "what did you touch?" in a calmer and calmer voice.
11. The agent ran all night and left one line: "Made several improvements." My teenager says that about the car.
12. "Production-ready" now means the agent said it with a rocket emoji.
13. Code review used to be reading a junior's 40-line PR; now it's skimming 4,000 lines from something that is never tired, and approving them because I am.
14. My agent hit its context limit and forgot why it opened the file. I've done that daily since 2009 and nobody ever offered me /compact.
15. When my coding agent forgets why it opened a file, it gets /compact. When I do it, I get a performance improvement plan.

## Pick

**#15.** It is specific to agents (`/compact` is a real command every agent user has typed), the setup is a
true daily observation, and the turn lands in the last three words with no explanation. The parallel
structure ("it gets... I get...") makes it read aloud cleanly to a room of developers. #14 is the same idea
told slower; #15 is the tighter version.
